DevOps for Cloud Computing, Assignment 2: Build, Containerize and Automate

About me

This page is my summary of Assignment 2 in DevOps for Cloud Computing: one small web page, taken through Git, GitHub, Docker and GitHub Actions.

What I accomplished

A. Git and GitHub

Public repository with a README, a .gitignore and 5+ meaningful commits. The extra section was added on the feature-endpoint branch, then merged through a pull request.

B. Docker

An nginx:alpine image that serves this page. I ran it locally on port 8080 and pushed it to Docker Hub as devops-a2:manual.

C. GitHub Actions

A workflow that checks this page, builds the image and pushes latest to Docker Hub only from main. Pull requests build but never push. Credentials come from GitHub secrets.

D. Webhook

A webhook sends push and pull request events to webhook.site, where I inspected the X-GitHub-Event header and the payload.

Pipeline in one line

commit → push to main → check page → build image → push to Docker Hub
